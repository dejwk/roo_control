# [roo_control 1.2.6](https://github.com/dejwk/roo_control/releases/tag/1.2.6)

Published 2026-08-29.

### Documentation

- Added a comprehensive programming guide covering GPIO I/O, buttons, relays, inert switches, PCF8574 expanders, remote bindings, and thermometers.
- Added a Documentation section to the README linking to the guide.

### Development and CI

- Updated host emulation to `roo_testing` 2.x with the Arduino ESP32 profile.
- Modernized GitHub Actions CI for pushes, pull requests, and manual runs.
- Added Bazelisk configuration and centralized AddressSanitizer support (`--config=asan`).

### Dependencies

- Updated minimum versions of `roo_logging`, `roo_quantity`, and `roo_scheduler`.

Full changelog: [`[1.2.5...1.2.6](https://github.com/dejwk/roo_control/compare/1.2.5...1.2.6)`](https://github.com/dejwk/roo_control/compare/1.2.5...1.2.6)
